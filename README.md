# Proyecto: Conversor de Tiempo

Este proyecto trata de desarrollar un programa que realice conversiones de tiempo:
✓ Horas a minutos
✓ Minutos a segundos
✓ Días a horas
✓ Semanas a días
El programa debe: mostrar el resultado de la conversión.

Las tecnologias usadas seran: 
html 
js 
css

Instrucciones: 
El usuario seleccionara el tiempo a convertir:
Horas a minutos
Minutos a segundos
Días a horas
Semanas a días  

ya seleccionado el tipo de conversion de ingresara una cantidad y al hhacer clic en convertir se mostrara dicha cantidad convertida
